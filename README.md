# Mesh Relations

A visual workspace for mapping nodes and their relationships.

## Overview

Mesh Relations is an interactive tool for creating, visualizing, and organizing network diagrams. Whether you're mapping system architectures, knowledge graphs, or complex relationships, Mesh Relations provides an intuitive interface to connect ideas and understand their interactions.

## Features

- **Visual Node Editor** - Easily create and connect nodes in an interactive canvas
- **Relationship Mapping** - Define and visualize connections between entities
- **Interactive Workspace** - Drag, zoom, and pan through your diagrams
- **TypeScript** - Built with modern TypeScript for type-safe development

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
git clone https://github.com/hsn-lab/mesh-relations.git
cd mesh-relations
npm install
```

### Usage

```bash
npm start
```

Visit `http://localhost:3000` to open the application.
